# skill-dump

A collection of agent skills for AI coding assistants (Claude Code, Cursor, GitHub Copilot, Windsurf, Zed, and more).

## Skills

| Skill | Description | Install |
|-------|-------------|---------|
| [conversion-psychology](./skills/conversion-psychology/) | Apply UX psychology principles (Smart Defaults, Goal Gradient, Reciprocity, IKEA Effect, Loss Aversion, Contrast Effect) to design high-converting UI across landing pages, onboarding, pricing, checkout, login flows, CTAs, and modals. Researches live patterns before writing code. | `npx skills add <owner>/skill-dump --skill conversion-psychology` |

## Usage

```bash
# Install a specific skill
npx skills add <owner>/skill-dump --skill conversion-psychology

# List all skills in this repo
npx skills add <owner>/skill-dump --list
```
